# 寫作工具流水線收藏

依照原始蒐集者註記，獨立整理，不納入 AZA-Animate-Skill-Navigator 的動畫候選。以下為[來源貼文](https://x.com/cnyzgkc/status/2107498419099209806)描述，未逐一驗證目前功能、安裝方式或授權。

| 階段 | 資源 | 來源描述與使用重點 |
|---|---|---|
| 選題 | [dbskill](https://github.com/dontbesilent2025/dbskill) | 檢查誰會看、為什麼會點開；先檢驗題目再動筆 |
| 寫稿結構 | [khazix-skills](https://github.com/KKKKhazix/khazix-skills) | 學習開頭與長文推進方式，不必整篇代寫 |
| 自查 | dbs-ai-check，來源稱包含於 [dbskill](https://github.com/dontbesilent2025/dbskill) | 先列出疑似 AI 痕跡供人工判斷；不是獨立倉庫，亦不是可靠的作者身分鑑定 |
| 局部潤色 | [Humanizer-zh](https://github.com/op7418/Humanizer-zh) | 處理已確認需要修改的句子，避免整篇盲目重寫 |
| 配圖 | [baoyu-skills](https://github.com/jimliu/baoyu-skills) | 封面、資訊圖與文中插圖 |
| 排版 | [gzh-design-skill](https://github.com/isjiamu/gzh-design-skill) | Markdown 轉公眾號使用的 HTML；貼入前實際預覽 |
| 二次分發 | [guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill) | 將文章核心觀點轉為網頁簡報；不假定能輸出 PowerPoint 檔案 |

建議順序：選題 → 草稿／結構 → 自查 → 人工確認 → 局部潤色 → 配圖 → 排版 → 視需要轉簡報。
